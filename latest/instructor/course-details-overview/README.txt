Open eduhub-instructor-course-details-overview.html. The HTML includes the main responsive CSS and JS, Bootstrap 5 and Font Awesome 6 styles bundled in the same file. The image is embedded as a base64 JPEG for standalone use. Assets folder also contains the local copy.

Shared layout markers: <!-- INCLUDE: partials/instructor-sidebar.html -->, instructor-topbar.html and instructor-mobile-navigation.html. These indicate partials that can replace the inline layout when integrated into a templating system.

Working prototype: sidebar nav, mobile drawer, tablet rail, account dropdown, notifications dropdown, global search Enter routes to My Courses; Edit Course and Manage Curriculum link to implemented files; course tabs link to future detail screens. View Public Course offers an explicit demo notice because the actual student-facing public course route is not present in the current package.

Data is static Figma sample data, not backend. Exact Figma image asset could not be downloaded; a bundled local illustration fallback is used. Do not use expired Figma URLs at runtime.

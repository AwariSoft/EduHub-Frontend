Deliverable
-----------
eduhub-instructor-dashboard.html — complete, stand-alone HTML page with Bootstrap 5/Font Awesome 6 CDN links, inline styles and JavaScript, and bundled offline Font Awesome fallback and course placeholder imagery.

Working frontend interactions:
- Collapse/expand desktop sidebar
- Open/close mobile instructor drawer and account/notification popovers
- Live course search / no-results indicator
- Switch course performance periods (sample data)
- Course, edit, view, and workspace navigation links
- Functional keyboard Escape/focus handling for menus

Notes
-----
All learner, revenue, and course values are sample Figma data, not live API results.
The original photograph files in Figma were not available as local assets. The page uses Unsplash images when online, with bundled illustrative fallback images for offline viewing. These are approximations rather than exact Figma photos.
Course-edit/view and other navigation links point to filename conventions for upcoming Instructor Workspace pages; those destinations must be supplied in the final project.
The source ZIP from earlier work used placeholder assets, so this implementation is independent of its global scripts.

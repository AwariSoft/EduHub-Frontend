EduHub Instructor Workspace — My Courses

Open eduhub-instructor-my-courses.html in any current browser. Single responsive HTML includes Bootstrap 5.3.3 and Font Awesome 6 Free with embedded offline CSS/fonts, images and JavaScript.

Figma frames:
Desktop: https://www.figma.com/design/CTtIqTcIqCn11h7d4XDOGC/EduHub?node-id=18-56531
Tablet: https://www.figma.com/design/CTtIqTcIqCn11h7d4XDOGC/EduHub?node-id=18-56692
Mobile: https://www.figma.com/design/CTtIqTcIqCn11h7d4XDOGC/EduHub?node-id=18-56818

Functionality: text search (both header and local), category/status filters, empty state/reset, per-course action dropdowns, account/notifications, sidebar collapse, mobile drawer and bottom navigation. Demo Duplicate emits an informational notice; it does not create a real course. Route links to instructor pages require corresponding files. No real backend or persistent course changes.

Design limitation: exact Figma temporary raster assets were unavailable for download; bundled illustration substitutes are included. The screen preserves the layout, visible text and statuses from Figma.

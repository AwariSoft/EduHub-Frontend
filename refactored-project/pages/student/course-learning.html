Variables and Data Types

About this lesson

Learn how C# stores information using variables and data types. Follow along as Ahmed declares values, names variables clearly and explains when to use int, string, double and bool.

What to practice

Declare three variables for a learner profile. Try changing their values, then print a short introduction to the console.

SQL Server Essentials

Build practical SQL skills with Microsoft SQL Server. Start with a clean local setup, learn to query relational data, and develop a well-structured database for a realistic course enrollment project.

Beginner level · English · 12 video lessons · 3 hr 12 min

Through guided demonstrations and hands-on exercises, learners practice joins, aggregation, constraints, stored procedures and transactions. Each section includes a downloadable SQL script and a focused exercise, with solutions explained in the following lesson.

Prerequisites

Basic computer skills. No previous SQL experience required. A Windows computer with SQL Server Developer Edition and SSMS is recommended.

Learning objectives

  • Write accurate queries using filtering, sorting, joins and aggregation.
  • Design normalized tables with appropriate keys, types and constraints.
  • Create views and stored procedures for reusable data access.
  • Use transactions to safely manage changes in an enrollment database.

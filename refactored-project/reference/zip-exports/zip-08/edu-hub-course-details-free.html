Course Description

A good database starts with good questions. This practical introduction walks you through gathering requirements, identifying entities and choosing the relationships that keep your information consistent.
You will design a small library database, turn an initial sketch into a normalized schema, and review common modeling mistakes. Short exercises help you practice each concept before moving on.
Who is this course for?
Students, aspiring analysts and developers who want a solid starting point in relational database design. No previous database experience is required.
Before you begin
Bring a notebook or diagramming tool and a real-world problem you would like to model.

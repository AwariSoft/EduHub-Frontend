Course Description

Start with the essentials and develop the confidence to write useful C# programs. Ahmed guides you through the language step by step, explaining not just how the code works, but why each concept matters.
You will configure your development tools, explore variables and operators, and build decision-making logic. Then bring everything together with object-oriented programming: classes, objects, inheritance and polymorphism.

Who is this course for?

New programmers and aspiring .NET developers. No previous C# experience is required; a computer and a willingness to practice are all you need.

Before you begin

Use a Windows, macOS or Linux computer with the .NET SDK and Visual Studio Code. Setup is covered in the first section.
